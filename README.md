# Les Loups Garoux de Thiergoland

## Objectif

Utiliser un LLM pour remplacer le MDJ (Maître du Jeu) et simuler la présence de villageois et loups-garous.
Le but final est de créer un jeu de rôle textuel complet.

## Technologies utilisées

- **Go** : Langage de programmation
- **LangChainGo** : Framework pour le développement d'applications basées sur des LLM
- **Ollama** : Serveur local pour l'exécution de LLM open-source
- **Qwen3** : Modèle LLM open-source
